KAIVO BRAND PACK — VERSION 1.1

BRAND IDEA
KAIVO is a premium operating identity for modern hospitality. The master wordmark uses custom vector geometry: a geometric K, crossbar-free Λ and a broken O with a narrow 18° cut centered at 3 o'clock.

PRIMARY TAGLINE
RUN YOUR BUSINESS. ELEVATE EXPERIENCES.

QUICK START
1. Read 08_Guidelines/KAIVO-Brand-Guidelines.pdf.
2. Use SVG for web and editable design work; PNG for transparent office/social use; EPS/PDF for Illustrator and print.
3. Use 02_Icons/Selected/KAIVO-Icon-Primary-* for favicon, app and social-avatar work.
4. Replace all .example contact and domain placeholders before publishing.

AI / ILLUSTRATOR COMPATIBILITY
Adobe Illustrator can open the SVG, EPS and vector PDF masters in this pack. A proprietary .ai file is not generated because Adobe Illustrator is not available in the build environment. Open a master SVG or EPS and use Save As > Adobe Illustrator (.ai) if required.
